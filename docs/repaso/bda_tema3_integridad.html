CALIDAD, LIMPIEZA Y VALIDACIÓN DE DATOS

Dimensiones de Calidad y Limpieza
  • Exactitud: El dato refleja el mundo real de forma verídica.
  • Completitud: No faltan valores críticos. Incluye la gestión de Valores Faltantes mediante sustitución o eliminación de nulos.
  • Consistencia: Ausencia de conflictos ilógicos. La Limpieza de Datos identifica y elimina estos errores sistemáticamente.
  • Trazabilidad y Validez: La Validez asegura que el campo acepte entradas según su formato. Ejemplo de Error Sintáctico: '2025-13-45'.
Great Expectations Framework

Herramienta pura en Python que actúa como un "test unitario para bases de datos". Evalúa los pipelines bloqueando el flujo si los datos no cumplen las expectativas, evitando ensuciar el Data Lake con duplicados o inconsistencias.

Estrategias de Corrección y Cuarentena

Zona de Cuarentena: Espacio de aislamiento para datos sospechosos que requieren análisis adicional.
Reprocesamiento: Estrategia de corrección que implica regenerar registros utilizando fuentes maestras para asegurar la integridad total.

ALGORITMOS DE INTEGRIDAD Y MANTENIMIENTO PREVENTIVO

Hash Criptográfico (ej. SHA-256) Suma de Verificación / Checksum (ej. CRC32)
Diseñado primariamente para imposibilitar robos e interceptaciones. Es pesado computacionalmente pero vital para la seguridad en el movimiento de workloads. Usa algoritmos de hash criptográficos para verificar la integridad de bloques de forma veloz. Detecta errores naturales como la pérdida de bits en HDFS.
  • Scrubbing (Ceph): Comparación silenciosa de checksums entre réplicas. Si una falla, se auto-repara fotocopiando la versión sana.
  • Erasure Coding (RS 6,3): Alternativa a la replicación x3. Divide el dato en fragmentos y añade paridad, permitiendo aguantar fallos de servidores ahorrando espacio.
  • Reparación Preventiva: Monitorización constante de métricas de hardware para anticipar degradaciones y prevenir fallos catastróficos.

MOVIMIENTO DE DATOS Y MIGRACIÓN DE WORKLOADS

Garantías de Migración Segura

Al migrar cargas de trabajo, se debe asegurar la integridad, compatibilidad y continuidad del servicio. No solo se mueven datos, sino también scripts y dependencias analíticas. Las Pruebas Paralelas validan el nuevo sistema antes de apagar el antiguo.

Hadoop DistCp

(Distributed Copy). Usa MapReduce para copiar Petabytes entre clústeres (ej: de On-Premise a Cloud) de forma masiva y distribuida.

Apache NiFi

Interfaz visual para orquestar flujos de datos vivos. Gestiona el movimiento de información de forma segura y altamente configurable.

Kafka MirrorMaker

Réplica topics de Kafka entre clústeres geográficamente distantes, garantizando la persistencia de los eventos en tiempo real.

LINAJE DE DATOS (DATA LINEAGE) Y GOBERNANZA

Apache Atlas (Gobernanza Visual)
  • Gobernanza: Imprescindible para evitar silos de datos y cumplir normativas legales.
  • Linaje del Dato: Apache Atlas indexa metadatos y grafica mapas donde se ve el origen y transformación de cada tabla (ej: "Este informe salió de Oozie filtrando datos de Kafka").
