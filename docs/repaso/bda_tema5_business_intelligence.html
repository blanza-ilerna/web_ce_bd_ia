FUNDAMENTOS DEL BUSINESS INTELLIGENCE (BI) Y ESTRATEGIA

Proceso ETL / ELT

(Extract, Transform, Load). Espina dorsal del BI. Los pipelines garantizan la calidad en la carga. Apache Spark permite transformaciones avanzadas en memoria para datasets masivos.

Data Warehouse (DWH)

Almacén histórico estructurado. La Arquitectura de Datos define aquí el almacenamiento y los esquemas. Debe garantizar la Gobernanza y calidad de los datos.

Métricas y ROI

La convergencia BI/Big Data aporta capacidad predictiva y prescriptiva. El ROI mide el impacto económico real de los modelos analíticos.

Análisis Multidimensional (Cubos OLAP)

Estructuras pre-calculadas que permiten analizar datos desde múltiples dimensiones. Operaciones estándar:

  • Drill-down / Roll-up: Aumentar o disminuir el nivel de detalle (ej: de Año a Mes).
  • Slice and Dice: Selección de subconjuntos de datos y rotación de dimensiones.

EL PROCESO KDD (Knowledge Discovery)

Metodología para transformar ruido digital en conocimiento accionable. Es un proceso iterativo que permite revertir fases si el modelo no es útil:

  1. Selección: Elegir milimétricamente los sistemas origen.
  2. Limpieza (Preprocesamiento): Eliminar duplicados, nulos e inconsistencias. Incluye el tratamiento de Outliers (valores atípicos).
  3. Transformación: Adaptar los datos (Scaling, Normalización). Incluye técnicas como One-hot Encoding para variables categóricas.
  4. Minería de Datos (Data Mining): Búsqueda de patrones. Algoritmo K-Means para la segmentación de datasets.
  5. Evaluación / Interpretación: Validación de los resultados para su uso ejecutivo.

ECOSISTEMA DE HERRAMIENTAS BI

Microsoft Power BI Tableau Qlik Sense Looker (Google)
Conecta con el ecosistema Office 365, DAX y Azure Synapse fluidamente. Líder en estética y exploración visual libre (Drag & Drop). Arquitectura basada en un "Motor Asociativo" sobre memoria RAM in-memory. Analítica nativa cloud sobre esquemas definidos con LookML (BigQuery).

INTEGRACIÓN Y DOBLE VALIDACIÓN FINAL

Arquitectura Bypass (Spark / Presto)

PowerBI se liga vía conector ODBC/JDBC lanzando consultas hacia motores remotos (Spark SQL). El clúster procesa petabytes y retorna solo el resultado limpio para su visualización.

Validación (Estadística vs Negocio)

1. Validación Estadística: ¿Goza el modelo de métricas matemáticas sólidas (AUC, precisión)?

2. Validación de Negocio: ¿Aporta valor real? ¿Es viable legalmente (RGPD)? Si no hay valor ejecutivo, el modelo se descarta.
