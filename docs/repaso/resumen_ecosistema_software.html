Resumen: Ecosistema de Software y Librerías

Diccionario técnico de herramientas de Ingesta, Procesamiento, IA, BI y Monitorización

1. INGESTA Y MOVIMIENTO (DATA PIPELINES)

Apache Sqoop SQL-Hadoop

Transferencia masiva de datos entre bases de datos relacionales (RDBMS) y Hadoop/HDFS usando conectores JDBC.

Apache Kafka Streaming

Plataforma de mensajería asíncrona "Pub-Sub". MirrorMaker se usa para replicar topics entre clústeres distantes.

Apache NiFi Orquestación

Herramienta visual para automatizar flujos de datos. Ideal para mover información entre sistemas con seguridad y control de errores.

Apache Flume Logs

Servicio distribuido y fiable para recolectar, agregar y mover grandes volúmenes de logs hacia HDFS.

Hadoop DistCp Copia

Herramienta de copia distribuida basada en MapReduce para mover petabytes entre clústeres Hadoop de forma masiva.

2. ALMACENAMIENTO, BASES DE DATOS Y FORMATOS

HDFS Storage

Sistema de Archivos Distribuido de Hadoop. Basado en NameNode (metadatos) y DataNodes (bloques de datos).

Delta Lake ACID Layer

Capa de almacenamiento de código abierto que aporta transacciones ACID al Data Lake sobre formatos como Parquet.

Apache HBase NoSQL

Base de datos NoSQL orientada a columnas sobre HDFS. Permite acceso aleatorio, lectura/escritura en tiempo real.

Formatos (Parquet/Avro) Serialización

Parquet: Almacenamiento columnar (rápido para lectura). Avro: Basado en esquemas (rápido para escritura).

3. PROCESAMIENTO Y CÓMPUTO DISTRIBUIDO

Apache Spark In-Memory

Motor de procesamiento ultrarrápido en memoria. Incluye Spark SQL, MLlib (IA) y Spark Streaming.

Apache Flink Real-Time

Motor de procesamiento de flujos de datos (streams) de muy baja latencia y alta tolerancia a fallos.

Apache Hive / Presto SQL Engine

Permiten ejecutar consultas SQL sobre el Data Lake. Presto destaca por su velocidad en análisis interactivos.

Apache Airflow / Oozie Scheduler

Airflow: Programación de tareas mediante DAGs en Python. Oozie: Orquestador basado en XML para trabajos Hadoop.

4. INTELIGENCIA ARTIFICIAL Y LIBRERÍAS

Scikit-Learn Machine Learning

Librería estándar para ML clásico en Python: regresiones, clasificación (Random Forest) y clustering (K-Means).

Keras / TensorFlow Google Deep Learning

Ecosistema desarrollado por Google para el entrenamiento de redes neuronales profundas (MLP, CNN, RNN).

PyTorch Meta Deep Learning

Framework de Deep Learning desarrollado por Meta (Facebook). Destaca por su flexibilidad y es ampliamente usado en investigación y producción.

Jupyter / Colab Notebooks

Entornos interactivos que facilitan la experimentación rápida y el prototipado de modelos mediante celdas de código ejecutables.

Great Expectations Data Quality

Framework de validación de datos que actúa como "tests unitarios para bases de datos" asegurando la calidad del pipeline.

Pandas / NumPy Data Prep

Librerías fundamentales para manipular y limpiar datos, así como operaciones de álgebra lineal sobre matrices masivas.

5. VISUALIZACIÓN, BI Y MONITORIZACIÓN

Power BI / Tableau BI Tools

Líderes en Dashboards interactivos. Power BI usa DAX; Tableau destaca en exploración visual libre.

Qlik Sense / Looker BI Tools

Qlik usa un motor asociativo in-memory; Looker se basa en modelado de datos con LookML.

Prometheus / Grafana Observability

Prometheus: Recolección de métricas de tiempo real. Grafana: Creación de paneles visuales para monitorizar hardware.

ELK Stack Log Analysis

Elasticsearch (Búsqueda), Logstash (Procesado) y Kibana (Visualización) para gestionar petabytes de logs.

6. GOBERNANZA, OPS Y ROBÓTICA

Apache Atlas Gobernanza

Catálogo de metadatos y gestión de Data Lineage (linaje del dato) para auditoría y cumplimiento.

Docker / Kubernetes Containers

Aislamiento de aplicaciones en contenedores ligeros y orquestación masiva de los mismos en clústeres.

ROS / MQTT Robotics/IoT

ROS: Middleware para robótica. MQTT: Protocolo pub-sub ultra-ligero para sensores IoT de bajo consumo.
