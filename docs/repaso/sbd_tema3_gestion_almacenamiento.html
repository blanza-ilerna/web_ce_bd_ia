REPOSITORIOS Y ESTRATEGIAS DE ALMACENAMIENTO

Data Warehouse (Estructurado)

Búnker tradicional blindado. Acumula datos empresariales 100% estructurados limpiados previamente (ETL puros). Histórico fácil de entender y preparado para Dashboards y SQL.

Data Lake (Crudo)

Océano masivo en bruto. Absorbe información sin discriminación (texto, logs, audios) usando la estrategia del volcado directo ELT. Clave para algoritmos de Machine Learning.

Data Lakehouse (Híbrido)

La fusión puntera (ej: Delta Lake). Combina la flexibilidad del Lago con la rigidez del Warehouse, permitiendo propiedades ACID y consultas SQL en tiempo real.

Almacenamiento en la Nube (Tiers)

Clasificación según acceso y coste:

  • Hot Storage: Datos críticos de uso frecuente y baja latencia.
  • Nearline (Warm): Punto intermedio para consultas ocasionales.
  • Cold / Archival: Datos históricos o legales de acceso muy poco frecuente.
OLTP vs OLAP

OLTP: Sistemas transaccionales que gestionan el día a día operativo.
OLAP: Sistemas analíticos para procesar consultas complejas sobre grandes históricos de datos.

ARQUITECTURA DISTRIBUIDA Y ZONAS DE DATOS

HDFS: El Corazón de Hadoop

Divide archivos masivos en bloques y los distribuye en un clúster:

  • NameNode (Maestro): Gestiona el índice de ubicaciones en RAM. Si falla sin backup, se pierde el acceso a todo el clúster.
  • DataNodes (Esclavos): Almacenan bloques físicos y los replican (por defecto 3 copias) para garantizar la tolerancia a fallos.
Zonificación de Datos

Zona de Entrada (Landing/Raw): Donde aterrizan los datos crudos.
Zona de Transformación (Curated): Donde los datos se limpian y enriquecen antes de su uso.

Virtualización de Datos

Permite consultar fuentes heterogéneas sin mover los datos físicamente, facilitando el acceso unificado en tiempo real.

INGESTA, GOBERNANZA Y HERRAMIENTAS

Apache Sqoop (El Traductor SQL)

Conecta bases de datos clásicas (SQL) con Hadoop. Paraleliza la carga mediante múltiples mappers. Debe ser idempotente para evitar duplicados.

Apache Flume (El Grifo de Logs)

Especializado en recolectar, agregar y mover grandes volúmenes de datos de streaming y logs de servidores directamente hacia HDFS.

Data Governance (Gobernanza)

Es el "Gobierno" del dato: políticas, roles y estándares que aseguran que el activo sea confiable, seguro y cumpla el RGPD.

Data Lineage (Linaje/Trazabilidad)

Es la "Historia" del dato: registro visual del recorrido completo y transformaciones desde su origen hasta el informe.
