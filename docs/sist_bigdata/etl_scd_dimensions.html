1.3.2.1 a) Slowly Changing Dimensions (SCD)

Preservando el pasado: estrategias para la gestión del historial de datos

En un Data Warehouse, los datos de las dimensiones (como clientes, productos o sedes) no son estáticos; cambian con el tiempo, pero lo hacen de forma lenta e impredecible. Las Slowly Changing Dimensions (SCD) son un conjunto de técnicas diseñadas para gestionar estos cambios, decidiendo si debemos sobrescribir la información o mantener un registro histórico de cómo eran los datos en el pasado.

Dominar las SCD es fundamental para realizar análisis de series temporales precisos. Sin ellas, perderíamos la capacidad de saber dónde vivía un cliente en el momento exacto en que realizó una compra hace dos años.

Tipologías de Cambio

Tipo 0

Fijo (Original)

Los datos nunca cambian una vez insertados. Ideal para atributos inmutables como la **fecha de nacimiento** o el código original de un producto.

Tipo 1

Sobrescritura (Actual)

El valor antiguo se reemplaza por el nuevo. No se mantiene historial. Es simple y ahorra espacio, pero imposibilita el análisis retrospectivo.

Tipo 2

Versionado (Historial Completo)

Se crea una nueva fila para cada cambio. Es el estándar en Big Data, ya que permite recrear el estado de cualquier registro en cualquier punto del tiempo.

Anatomía de una Dimensión de Tipo 2

Para implementar el versionado, añadimos metadatos técnicos a la tabla. Esto permite que el motor de consultas sepa qué fila era la "verdadera" en una fecha determinada.

Campos Técnicos Clave

  • Surrogate Key: ID único para cada versión (PK).
  • Effective Date: Fecha de inicio de validez.
  • End Date: Fecha de fin (9999-12-31 si es actual).
  • Current Flag: Indicador booleano de registro activo.

Beneficio Analítico

Permite unir la tabla de hechos (ventas) con la versión exacta de la dimensión (cliente) que existía en el momento de la transacción, garantizando la **integridad referencial histórica**.

Ejemplo: Cambio de Sede de Cliente

SK ID_Cliente Ciudad Inicio Fin Actual
101 A-55 Madrid 2022-01-01 2023-05-14 N
542 A-55 Barcelona 2023-05-15 9999-12-31 Y
Si consultamos las ventas de marzo de 2023, el sistema usará el registro de Madrid automáticamente.

El Valor de la Trazabilidad

La implementación de SCD Tipo 2 es el pilar de la inteligencia de negocio avanzada. Permite no solo reportar el presente, sino entender la evolución histórica del ecosistema de datos, detectando patrones de cambio que de otro modo quedarían ocultos tras la sobrescritura de datos.
