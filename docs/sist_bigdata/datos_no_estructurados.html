1.3.3.3 Extracción de Datos No Estructurados

NLP: Extrayendo estructura y significado del lenguaje humano

La mayor parte de la información generada hoy en día —emails, documentos, redes sociales o transcripciones— carece de un formato rígido. Extraer valor de estos datos no estructurados requiere técnicas de **Procesamiento de Lenguaje Natural (NLP)** para transformar el texto libre en variables cuantitativas que una máquina pueda analizar.

El objetivo no es solo leer las palabras, sino comprender el contexto, identificar entidades y cuantificar el sentimiento oculto en el mensaje.

Arquitectura del Procesamiento de Texto

✂️

Tokenización y Limpieza de Ruido

División del texto en unidades básicas (**tokens**). Se eliminan las *stopwords* (palabras frecuentes sin valor analítico como "el", "de", "y") para reducir el ruido y centrar el análisis en términos informativos.

🌱

Normalización Morfológica

Reducción a la raíz o forma base. El **Stemming** corta sufijos de forma heurística ("corr-"), mientras que la **Lematización** usa diccionarios para obtener el lema correcto ("correr"), permitiendo agrupar variaciones de una misma idea.

🏷️

Reconocimiento de Entidades (NER)

Identificación automática de nombres propios, organizaciones, lugares y fechas. Convierte un párrafo en una lista estructurada de actores y ubicaciones, facilitando el análisis de red.

Análisis de Sentimiento y Filtrado (Python / NLTK)

sentiment_analysis.py 
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from nltk.sentiment import SentimentIntensityAnalyzer

def analizar_opinion_cliente(texto):
    # 1. Normalización y Tokenización
    tokens = word_tokenize(texto.lower())
    
    # 2. Filtrado de Stopwords y caracteres especiales
    stop_words = set(stopwords.words('spanish'))
    limpios = [t for t in tokens if t not in stop_words and t.isalpha()]
    
    # 3. Análisis de Sentimiento Cuantitativo
    sia = SentimentIntensityAnalyzer()
    puntuacion = sia.polarity_scores(texto)
    
    return {
        'riqueza_lexica': len(set(limpios)),
        'sentimiento_global': puntuacion['compound'] # -1 (negativo) a +1 (positivo)
    }
