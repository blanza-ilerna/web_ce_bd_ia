1.6.1.2 Dimensión: Completitud (Completeness)

La visión integral del dato: ¿tenemos toda la información necesaria para decidir?

La completitud evalúa si el dataset contiene todos los elementos necesarios para un análisis válido. Los datos incompletos no solo limitan la profundidad del conocimiento, sino que pueden introducir sesgos peligrosos si los valores faltantes no son aleatorios (ej. si solo faltan los ingresos de los usuarios de una región específica). Garantizar la completitud es vital para asegurar que la muestra sea representativa de la población total.

Un dataset con una exactitud del 100% en sus registros pero con una completitud del 10% es prácticamente inútil para la toma de decisiones estratégicas.

Niveles de Falta de Información

👤

Ausencia de Registros Completos

Entidades que deberían existir en el sistema pero no se han capturado (ej. clientes que abandonan el proceso de registro antes de finalizar).

📑

Huecos de Atributos (Nulos)

Registros existentes donde faltan campos críticos (ej. facturas sin fecha de vencimiento o perfiles sin número de teléfono).

📅

Incompletitud Temporal (Brechas)

Periodos de tiempo sin datos en una serie temporal (ej. tenemos métricas de enero y marzo, pero un fallo en el servidor borró los datos de febrero).

Evaluando el Impacto y la Causa

¿Por qué faltan los datos?

  • Diseño: Campos marcados como opcionales en el formulario original.
  • Técnico: Fallos en la integración o pérdida de paquetes en el transporte.
  • Usuario: Abandono del proceso por complejidad o desconfianza.

Análisis de Criticidad

Un 5% de nulos aleatorios suele ser tolerable mediante técnicas de imputación. Sin embargo, si falta el 90% de un campo clave (ej. email en una campaña de marketing), la base de datos pierde su valor operativo.

Auditoría de Completitud Automática (Python)

completeness_audit.py 
import pandas as pd

def generar_informe_completitud(df):
    """Calcula el porcentaje de datos no nulos por cada columna"""
    resumen = []
    total_filas = len(df)
    
    for columna in df.columns:
        datos_presentes = df[columna].notna().sum()
        tasa = (datos_presentes / total_filas) * 100
        
        resumen.append({
            'Campo': columna,
            'Registros Presentes': datos_presentes,
            'Tasa Completitud': f"{tasa:.2f}%"
        })
    
    return pd.DataFrame(resumen).sort_values(by='Tasa Completitud', ascending=False)

# Ejecución de la auditoría sobre un dataset de ejemplo
df_auditoria = generar_informe_completitud(df_ventas)
print(df_auditoria)

Hacia una Visión 360º

La completitud es el termómetro de nuestra cobertura informativa. Monitorizar esta métrica nos permite identificar qué canales de captura están fallando y dónde estamos perdiendo oportunidades de conocimiento crítico para el negocio.
