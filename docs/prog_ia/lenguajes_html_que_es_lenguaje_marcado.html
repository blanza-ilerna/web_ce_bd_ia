¿Qué es un Lenguaje de Marcado?

La estructura y el significado detrás de la información digital

Un lenguaje de marcado es un sistema diseñado para estructurar, organizar y describir el contenido de un documento mediante etiquetas o marcas. A diferencia de los lenguajes de programación, su objetivo no es ejecutar algoritmos, sino definir la jerarquía y el propósito de cada fragmento de información.

Marcado vs. Programación

Es fundamental entender que, aunque ambos utilizan texto, sus propósitos son diametralmente opuestos:

💻 Programación (Python)

Ejecuta acciones y lógica. Ordena al ordenador realizar cálculos o controlar procesos.

print("Hola mundo") # Acción: mostrar texto

🏷️ Marcado (HTML)

Describe el contenido. Indica qué parte es un título, un párrafo o una imagen.

<p>Hola mundo</p> <!-- Descripción: es un párrafo -->

El Concepto de "Marcar"

El término proviene de la idea de realizar anotaciones sobre un texto para identificar su rol dentro del documento.

Estructura de una Etiqueta

La mayoría de los elementos se encierran entre una etiqueta de apertura y otra de cierre:

<etiqueta> Contenido </etiqueta>

Función Semántica

Cada etiqueta aporta un significado que permite a los navegadores o motores de búsqueda interpretar correctamente los datos.

Ejemplo en HTML

Observa cómo las etiquetas definen distintos tipos de elementos en una página web:

ejemplo.html 
<h1>Título principal</h1>
<p>Este es un párrafo de texto que forma parte del cuerpo del documento.</p>
<img src="imagen.jpg" alt="Descripción de la imagen">
1

<h1>: Define un encabezado de nivel superior.

2

<p>: Encierra un bloque de texto como párrafo.

3

<img>: Etiqueta "vacía" o autocontenida que inserta un recurso visual.

💡 Conclusión

Un lenguaje de marcado no realiza cálculos por sí mismo; su potencia reside en cómo organiza la información para que sea procesada o presentada correctamente por otros programas (como un navegador web). Es la base fundamental para la web, la descripción de datos y la comunicación técnica entre sistemas modernos.
