Etiquetas Vacías o Autocontenidas

Elementos que no requieren cierre para definir su función

A diferencia de los elementos que envuelven contenido, algunas etiquetas se bastan por sí mismas para representar un recurso o una acción. Estas se conocen como etiquetas vacías o autocontenidas, ya que no poseen contenido interno ni requieren una etiqueta de cierre.

Formas de Escritura

Dependiendo del estándar (HTML tradicional o XML/XHTML), estas etiquetas pueden presentarse de dos maneras:

🌐 HTML Tradicional

Se utiliza únicamente la etiqueta de apertura. El navegador interpreta automáticamente su finalización.

<img src="foto.jpg">
<br>

📜 XML / XHTML

Se incluye una barra inclinada al final del nombre para indicar explícitamente que la etiqueta se cierra a sí misma.

<img src="foto.jpg" />
<hr />

Ejemplos Esenciales

Estas son algunas de las etiquetas vacías más utilizadas en el desarrollo web y la estructuración de documentos:

🖼️

<img>

Inserta una imagen externa en el documento utilizando el atributo src.

⏎

<br>

Produce un salto de línea dentro de un bloque de texto.

➖

<hr>

Genera una línea horizontal para separar temáticamente secciones de contenido.

💡 Interpretación Directa

En todos estos casos, la etiqueta es interpretada por el sistema como un elemento atómico. No espera contenido adicional ni una marca de cierre posterior, lo que simplifica la estructura en puntos donde solo se requiere insertar un recurso o un formato específico.
