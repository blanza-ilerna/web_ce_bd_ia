Etiquetas de Apertura y Cierre

La estructura básica de los elementos pares en el marcado

Las etiquetas de apertura y cierre son el estándar más común en los lenguajes de marcado. Funcionan como contenedores que delimitan exactamente dónde empieza y dónde termina un fragmento de contenido o una sección del documento.

Anatomía de un Elemento Par

Un elemento completo se compone de tres partes fundamentales que trabajan en conjunto:

🔓 Etiqueta de Apertura

Marca el inicio del elemento. Se escribe entre los signos < y >.

🔒 Etiqueta de Cierre

Indica el final. Se distingue por incluir una barra inclinada (/) antes del nombre.

ejemplo_par.html 
<p>Este es un párrafo de texto.</p>

Desglose del Ejemplo

1

<p>: Es la etiqueta que abre el párrafo.

2

Este es un párrafo...: Es el contenido interno del elemento.

3

</p>: Es la etiqueta que cierra y finaliza el bloque.

💡 Base de la Jerarquía

Este sistema de pares no solo delimita texto, sino que permite el anidamiento: unas etiquetas pueden contener a otras, permitiendo construir estructuras complejas y profundas que dan vida a la web moderna y a los sistemas de datos estructurados.
