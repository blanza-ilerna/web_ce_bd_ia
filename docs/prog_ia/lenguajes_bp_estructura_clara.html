Estructura Clara y Coherente

Jerarquía, anidamiento y legibilidad técnica

Un documento de marcado profesional debe mantener una estructura jerárquica perfectamente definida. Esto implica que las etiquetas deben abrirse y cerrarse de forma ordenada, respetando el anidamiento y evitando cualquier tipo de solapamiento que confunda a los sistemas de procesamiento.

Anidamiento Correcto

La regla fundamental es: "Lo último que se abre es lo primero que se cierra". Observa la diferencia entre una estructura válida y una errónea:

✅ Ejemplo Correcto

Las etiquetas se anidan sin solaparse:

<p>Este es un <strong>texto importante</strong> dentro de un párrafo.</p>

❌ Ejemplo Incorrecto

Las etiquetas se cierran en el orden equivocado:

<p>Este es un <strong>texto importante</p></strong>

⚠️ Consecuencias del solapamiento

El ejemplo incorrecto produce un error de interpretación (parsing error). Un navegador podría intentar corregirlo, pero un sistema de IA o un servicio web de intercambio de datos podría fallar completamente o interpretar la información de forma sesgada.

Legibilidad mediante Indentación

Aunque las máquinas suelen ignorar los espacios en blanco, para los humanos es vital indentar el contenido (dejar sangrías) para visualizar la jerarquía rápidamente:

datos_estructurados.json 
{
    "imagen": "gato1.jpg",
    "etiquetas": [
        "animal",
        "mamífero",
        "gato"
    ]
}
📐

Estructura Visual: La indentación permite identificar de un vistazo qué elementos pertenecen a una categoría superior.

🛠️

Mantenimiento: Un código limpio y ordenado es mucho más fácil de depurar y escalar en el futuro.
