Tipos de Etiquetas: El Corazón del Marcado

Clasificación y funciones esenciales para la estructuración de documentos

Las etiquetas son los átomos de cualquier lenguaje de marcado. No todas son iguales: cada una tiene una forma y una misión específica dentro del documento. Conocer sus diferentes tipologías es clave para construir estructuras que sean comprensibles tanto para personas como para sistemas automatizados.

Funciones y Formas

El ecosistema de etiquetas se divide principalmente según cómo interactúan con el contenido y qué significado aportan:

🧱 Por su Forma

Etiquetas que requieren cierre para envolver contenido frente a etiquetas autocontenidas que representan elementos únicos.

🧠 Por su Función

Desde etiquetas que puramente definen el formato visual hasta aquellas que aportan un valor semántico profundo al documento.

Organización y Comprensión

📋 Orden Lógico

La correcta combinación de etiquetas permite crear documentos organizados, donde la jerarquía de la información es evidente a simple vista.

🤖 Interoperabilidad

Un uso estandarizado de los tipos de etiquetas asegura que cualquier sistema (un navegador, un bot o una IA) pueda interpretar el contenido sin ambigüedades.

💡 Punto de Partida
