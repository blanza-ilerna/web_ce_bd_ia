Etiquetas Semánticas

Aportando significado y estructura lógica al contenido web

Las etiquetas semánticas son aquellas que, además de definir la forma o el estilo visual, aportan significado claro sobre el contenido que encierran. Se utilizan principalmente en HTML5 para que la estructura del documento sea comprensible tanto para humanos como para máquinas.

Propósito y Utilidad

A diferencia de etiquetas genéricas como <div> o <span> (que no dicen nada sobre su contenido), las etiquetas semánticas indican explícitamente qué función cumple cada parte del documento:

🔍 Motores de Búsqueda

Ayudan al SEO permitiendo que buscadores como Google entiendan qué partes son el encabezado, el contenido principal o el pie de página.

♿ Accesibilidad

Facilitan la navegación a personas que utilizan lectores de pantalla, permitiéndoles saltar directamente a secciones relevantes.

Ejemplos de Etiquetas Semánticas

🔝

<header>

Define el encabezado de una página o una sección, conteniendo normalmente el logo y la navegación.

📰

<article>

Representa una composición autónoma en un documento, como una entrada de blog o una noticia.

🔚

<footer>

Indica el pie de página o de una sección, con información de autoría, enlaces legales o contacto.

ejemplo_semantica.html 
<header>
    <h1>Encabezado de la página</h1>
</header>

<article>
    <h2>Contenido principal del artículo</h2>
    <p>Este es el cuerpo del texto con valor semántico.</p>
</article>

<footer>
    <p>Pie de página &copy; 2024</p>
</footer>

💡 Más allá del aspecto visual

Recuerda que estas etiquetas permiten identificar de manera semántica qué función cumple cada parte del documento. Su uso es una buena práctica fundamental en el desarrollo web moderno para garantizar la interoperabilidad y la calidad del código.
