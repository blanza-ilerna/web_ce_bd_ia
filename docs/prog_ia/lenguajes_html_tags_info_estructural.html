Información Estructural

El esqueleto y la jerarquía de los documentos marcados

La información estructural determina la forma en que se organiza el contenido de un documento. A través de las etiquetas, establecemos una jerarquía clara y definimos las relaciones de parentesco (anidamiento) entre los diferentes elementos.

Jerarquía y Relación

La estructura permite que el sistema entienda el orden de importancia y la agrupación de los datos:

🔝 Jerarquía

Diferencia entre títulos principales, subtítulos, párrafos y listas para guiar la lectura.

📦 Agrupación

Permite encerrar elementos relacionados dentro de contenedores superiores (como un artículo o una sección).

Ejemplo de Organización Estructural

Observa cómo las etiquetas construyen una estructura lógica para un tema sobre energía:

estructura_ejemplo.html 
<article>
    <h1>La energía solar</h1>
    <p>La energía solar es una fuente renovable que utiliza la radiación del Sol.</p>
    <ul>
        <li>Paneles fotovoltaicos</li>
        <li>Colectores térmicos</li>
    </ul>
</article>
📦

<article>: Actúa como contenedor raíz que agrupa todo el tema.

🔖

<h1>: Establece el nivel máximo de jerarquía (título principal).

📝

<p>: Identifica un bloque de texto informativo.

📜

<ul> / <li>: Organizan datos relacionados en una lista jerárquica.

💡 Interpretación Universal

Esta estructura sólida permite que un navegador, un motor de búsqueda o un lector de pantalla entienda perfectamente cómo está organizado el documento, independientemente de cómo se visualice estéticamente.
