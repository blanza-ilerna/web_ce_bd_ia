Uso Adecuado de las Etiquetas

Priorizando el significado sobre la apariencia visual

Una de las reglas de oro del marcado profesional es que cada etiqueta debe emplearse según su función. No debemos elegir una etiqueta basándonos en cómo queremos que se vea el contenido, sino en qué es ese contenido. La apariencia visual debe ser responsabilidad exclusiva de las hojas de estilo (CSS).

Semántica y Accesibilidad

Utilizar las etiquetas correctas mejora drásticamente la capacidad de los navegadores y motores de búsqueda para entender el documento:

🔍 SEO Mejorado

Los motores de búsqueda identifican mejor las partes relevantes del sitio (títulos, artículos, pies de página).

♿ Inclusión

Los lectores de pantalla para personas con discapacidad visual pueden navegar por el contenido de forma lógica.

Ejemplo de Etiquetas Semánticas

Observa cómo estas etiquetas definen claramente la estructura y función de cada sección sin necesidad de estilos adicionales:

semantica_correcta.html 
<header>Encabezado principal</header>
<article>Contenido principal del artículo</article>
<footer>Pie de página con información legal</footer>
🏛️

<header> y <footer>: Identifican los bloques de inicio y cierre de una sección o página.

📄

<article>: Define un contenido independiente que tiene sentido por sí mismo (como una noticia o post).

💡 Regla General

Si usas un <h1> solo porque quieres que el texto sea grande, estás cometiendo un error. Usa el <h1> porque es el título más importante, y si no te gusta el tamaño, cámbialo con CSS. El marcado define el significado; el diseño define la forma.
