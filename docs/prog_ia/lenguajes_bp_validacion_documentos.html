Validación de Documentos

Asegurando la integridad y cumplimiento de estándares técnicos

La validación es el proceso técnico de comprobar que un documento cumple estrictamente con las reglas del lenguaje y las restricciones de su esquema. Este proceso permite detectar errores de sintaxis, etiquetas mal cerradas o estructuras de datos inconsistentes antes de que causen fallos en el sistema.

Herramientas de Validación

🌐 HTML

Uso de servicios como el W3C Validator (validator.w3.org) para verificar el cumplimiento del estándar web.

🏗️ XML

Validación mediante DTD (reglas básicas) o XML Schema (XSD) para definiciones complejas y tipos de datos estrictos.

📄 JSON

Implementación de JSON Schema, estableciendo un "contrato" de datos para APIs y bases de datos NoSQL.

Validación Estricta: XML y XSD

El esquema XSD actúa como un molde que define qué elementos son obligatorios y qué tipo de información pueden contener:

datos_producto.xml
<producto>
    <codigo>AI-100</codigo>
    <stock>45</stock>
</producto>
esquema.xsd
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="producto">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="codigo" type="xs:string"/>
        <xs:element name="stock" type="xs:integer"/>
      </xs:sequence>
    </xs:complexType>
  </xs:element>
</xs:schema>

Validación Moderna: JSON Schema

Define reglas lógicas para asegurar que los objetos recibidos en una API sean válidos:

validacion_api.json 
{
    "$schema": "http://json-schema.org/draft-07/schema#",
    "type": "object",
    "properties": {
        "sku": { "type": "string", "minLength": 5 },
        "precio": { "type": "number", "minimum": 0 },
        "categoria": { "enum": ["hardware", "software", "servicio"] }
    },
    "required": ["sku", "precio"]
}

Este esquema asegura que el campo sku sea texto, el precio sea un número positivo y la categoría pertenezca a una lista predefinida.
