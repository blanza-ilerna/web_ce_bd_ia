Estructura Básica de un Documento Marcado

Jerarquía, anidamiento y sintaxis fundamental de la información estructurada

Un documento de marcado se organiza mediante etiquetas que delimitan el contenido, creando una estructura jerárquica. Esta organización permite que tanto humanos como sistemas informáticos interpreten la información de manera coherente y predecible.

1. Etiquetas y Atributos: Los Bloques de Construcción

La unidad fundamental es la etiqueta (tag), pero su funcionalidad se extiende mediante los atributos.

🏷️ Apertura y Cierre

La mayoría de los elementos requieren un inicio y un fin para delimitar el alcance del marcado.

<titulo>Introducción</titulo>

⚙️ Atributos y Valores

Ofrecen información adicional o propiedades específicas del elemento.

<img src="foto.jpg" alt="Retrato">

2. Jerarquía y Anidamiento

Los documentos de marcado no son planos; se organizan en forma de árbol, donde unas etiquetas contienen a otras.

estructura_jerarquica.xml 
<articulo>
    <titulo>La evolución de la IA</titulo>
    <parrafo>
        La IA ha progresado gracias al <strong>poder de cómputo</strong>.
    </parrafo>
</articulo>

En este ejemplo, <articulo> es el elemento padre que contiene a <titulo> y <parrafo>.

3. El Ejemplo Clásico: Documento HTML

Aunque cada lenguaje tiene sus reglas, la estructura general suele separar la información técnica del contenido visible.

📂 Cabecera (<head>)

Contiene metadatos, títulos de página, enlaces a estilos y scripts. Es información no visible directamente para el usuario.

🖼️ Cuerpo (<body>)

Incluye todo el contenido visible: encabezados, párrafos, imágenes, enlaces y componentes interactivos.

index.html 
<html>
    <head>
        <title>Título de la Pestaña</title>
    </head>
    <body>
        <h1>Bienvenidos</h1>
        <p>Este es el contenido principal.</p>
    </body>
</html>

4. Etiquetas Vacías o Autocontenidas

Algunos elementos no tienen contenido interno ni requieren una etiqueta de cierre explícita.

💡

Ejemplos comunes incluyen saltos de línea (<br>), líneas horizontales (<hr>) o inserción de recursos externos (<img>).

💡 Conclusión

Comprender la estructura básica (etiquetas, atributos y jerarquía) es el primer paso para dominar cualquier lenguaje de marcado. Esta lógica de "cajas dentro de cajas" es la que permite construir desde documentos sencillos hasta aplicaciones web complejas y sistemas de intercambio de datos masivos.
