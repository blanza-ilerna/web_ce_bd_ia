Atributos y Metadatos

Enriqueciendo los elementos con información técnica y descriptiva

Además de las etiquetas en sí, los lenguajes de marcado permiten añadir atributos. Estos componentes proporcionan información adicional y específica sobre un elemento, permitiendo configurar su comportamiento, origen o propiedades técnicas sin modificar el contenido principal.

Sintaxis y Estructura

Los atributos se integran siempre dentro de la etiqueta de apertura y siguen un estándar universal de par clave-valor:

<etiqueta nombre="valor">

🏷️ Nombre

Identifica la propiedad que queremos definir (ej: src, href, id).

💎 Valor

Especifica el dato concreto de esa propiedad, siempre entrecomillado.

Caso de Uso: Elementos Multimedia

Los atributos son fundamentales para que el sistema sepa cómo interpretar y mostrar recursos externos como imágenes:

atributos_imagen.html 
<img src="paisaje.jpg" alt="Vista de un valle al amanecer" width="600" height="400">
📂

src (source): Especifica la ruta o ubicación del archivo de imagen.

♿

alt (alternative text): Proporciona una descripción textual vital para la accesibilidad y el SEO.

📏

width / height: Definen las dimensiones técnicas del elemento en el documento.

💡 Metadatos invisibles

Muchos atributos actúan como metadatos que ayudan a interpretar o mostrar el contenido correctamente, sin formar parte del texto que el usuario lee directamente. En proyectos de IA, estos atributos son esenciales para etiquetar datos de entrenamiento y metadatos de archivos masivos.
