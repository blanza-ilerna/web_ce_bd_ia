2.3.6.3 Apache Cassandra

Disponibilidad total: arquitectura descentralizada para escalas globales

Apache Cassandra es una base de datos NoSQL distribuida, diseñada específicamente para gestionar volúmenes masivos de datos a través de múltiples servidores estándar. Su arquitectura se basa en un modelo peer-to-peer (sin nodo maestro), lo que elimina cualquier punto único de fallo y permite una escalabilidad lineal sin precedentes.

Es la herramienta de referencia para aplicaciones que no pueden permitirse ni un segundo de inactividad, ofreciendo un control total sobre el equilibrio entre consistencia y disponibilidad.

Pilares Técnicos de Cassandra

🌐

Arquitectura Peer-to-Peer

Todos los nodos son idénticos y se comunican mediante un protocolo de cotilleo (*gossip*). Al no existir un nodo maestro, el sistema es intrínsecamente tolerante a fallos y extremadamente resiliente.

⚖️

Consistencia Ajustable (AP)

Permite configurar el nivel de consistencia por cada operación. Se puede priorizar la disponibilidad absoluta (AP) mediante la consistencia eventual para obtener respuestas ultrarrápidas.

⏱️

Optimización para Series Temporales

Su modelo de datos es ideal para registros cronológicos masivos, lo que la convierte en la opción predilecta para el almacenamiento de métricas IoT y logs de alta concurrencia.

Aplicación Práctica: Netflix y el Streaming Masivo

🎬

Gestión de Perfiles y Metadatos

Netflix utiliza Cassandra como su base de datos principal para gestionar los perfiles de usuario y el historial de visualización a nivel mundial. La capacidad de replicar datos de forma transparente entre múltiples centros de datos asegura que la experiencia de usuario sea idéntica y fluida en cualquier continente.
