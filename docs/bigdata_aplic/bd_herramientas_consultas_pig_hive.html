2.3.5 Consultas con Apache Pig y Apache Hive

Abstracciones de alto nivel: simplificando el procesamiento distribuido

Escribir jobs MapReduce en Java puro puede ser una tarea ardua y propensa a errores. Para solventar este cuello de botella, surgieron herramientas como Apache Pig y Apache Hive. Estas capas de abstracción permiten a los analistas e ingenieros de datos ejecutar transformaciones complejas y consultas analíticas sobre HDFS utilizando lenguajes mucho más sencillos y potentes.

Mientras que Pig se enfoca en flujos de datos procedimentales (ETL), Hive ofrece una interfaz declarativa similar al SQL tradicional para el Data Warehousing masivo.

Apache Pig: Procesamiento Flujo a Flujo

Pig Latin es un lenguaje procedimental que permite definir transformaciones de datos de forma concisa. El motor de Pig traduce estos scripts automáticamente en una serie de trabajos MapReduce o Spark altamente optimizados.

script_ventas.pig
-- Carga de datos con esquema definido
ventas = LOAD '/data/ventas.csv' USING PigStorage(',') 
         AS (id:int, producto:chararray, precio:float);

-- Filtrado de productos premium
filtradas = FILTER ventas BY precio > 100;

-- Agrupación y conteo
agrupadas = GROUP filtradas BY producto;
totales = FOREACH agrupadas GENERATE group, COUNT(filtradas);

-- Almacenamiento en HDFS
STORE totales INTO '/salidas/totales' USING PigStorage(',');
Impacto: Reduce el tiempo de desarrollo en un 50% comparado con MapReduce puro, permitiendo transformaciones complejas en pocas líneas de código.

Apache Hive: Data Warehousing sobre Hadoop

HiveQL es un lenguaje declarativo muy similar al SQL tradicional. Está diseñado específicamente para consultas analíticas sobre grandes volúmenes de datos almacenados en HDFS o S3, permitiendo a analistas de BI trabajar sin conocimientos de programación distribuida.

definicion_tabla.sql
CREATE EXTERNAL TABLE ventas (
    id INT,
    producto STRING,
    precio FLOAT
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
LOCATION '/data/ventas/';
consulta_analitica.sql
SELECT producto, COUNT(*) AS total
FROM ventas
WHERE precio > 100
GROUP BY producto;
Diferencia Crítica: A diferencia del SQL relacional, HiveQL no está diseñado para transacciones en tiempo real; es un motor optimizado para el procesamiento batch masivo.

Ejemplos de Consultas Analíticas

💰 Ingresos por Región

SELECT region, SUM(precio) AS total_ventas
FROM ventas
GROUP BY region;

🏆 Top 10 Productos

SELECT producto, COUNT(*) AS frecuencia
FROM ventas
GROUP BY producto
ORDER BY frecuencia DESC
LIMIT 10;
