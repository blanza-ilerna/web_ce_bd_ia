1.7 Pipeline con AWS SageMaker y S3

Implementación práctica de un flujo de entrenamiento y despliegue en la nube

A continuación, se presenta un ejemplo de código en Python utilizando las bibliotecas Boto3 y el SDK de SageMaker. Este script implementa un pipeline completo de análisis predictivo para una empresa de retail, cubriendo desde la ingesta de datos en S3 hasta el despliegue de un endpoint para predicciones en tiempo real.

Este flujo permite automatizar el ciclo de vida del modelo, asegurando que el entrenamiento sea escalable y el despliegue sea altamente disponible.

Implementación del Pipeline

pipeline_sagemaker.py 
import boto3
import sagemaker
from sagemaker.estimator import Estimator
from sagemaker.inputs import TrainingInput

# Configurar cliente de AWS y sesión de SageMaker
s3_client = boto3.client('s3')
sagemaker_session = sagemaker.Session()

# Definir bucket y rutas de datos
bucket = 'retail-data'
train_data = f's3://{bucket}/train/sales_data.csv'
output_path = f's3://{bucket}/output/'

# Configurar el modelo en SageMaker (Linear Learner)
role = 'arn:aws:iam::YOUR_ACCOUNT_ID:role/SageMakerRole'
estimator = Estimator(
    image_uri=sagemaker.image_uris.retrieve('linear-learner', region='us-east-1'),
    role=role,
    instance_count=1,
    instance_type='ml.m5.large',
    output_path=output_path,
    sagemaker_session=sagemaker_session
)

# Configurar los datos de entrada para el entrenamiento
train_input = TrainingInput(s3_data=train_data, content_type='text/csv')

# Iniciar el entrenamiento del modelo
estimator.fit({'train': train_input})

# Desplegar el modelo como un endpoint de inferencia
predictor = estimator.deploy(
    initial_instance_count=1,
    instance_type='ml.t2.medium',
    endpoint_name='retail-demand-prediction'
)

# Realizar una predicción de prueba
# [ventas_históricas, índice_estacional, promoción]
data = [[1000, 1.2, 1]] 
prediction = predictor.predict(data)
print(f"Predicción de demanda generada: {prediction}")

Componentes del Pipeline

Este código ilustra un pipeline robusto que carga datos directamente desde Amazon S3, entrena un modelo de regresión (Linear Learner) en la infraestructura escalable de SageMaker y lo implementa automáticamente como un endpoint RESTful. Este patrón es la base de las arquitecturas MLOps modernas, permitiendo la integración con servicios de procesamiento masivo como Amazon EMR para datasets de escala petabyte.
