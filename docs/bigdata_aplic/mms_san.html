1.2.2.3 SAN (Storage Area Network)

Infraestructura crítica para el máximo rendimiento y disponibilidad empresarial

Una SAN es una red de área local dedicada exclusivamente al tráfico de almacenamiento, separada de la red LAN de usuarios. Proporciona acceso a nivel de bloque, lo que permite que los servidores vean los volúmenes remotos como si fueran discos duros locales instalados físicamente.

Utiliza tecnologías de alto rendimiento como Fibre Channel (FC) o iSCSI sobre 10/40/100 GbE para garantizar una latencia ultra-baja y una fiabilidad extrema.

✅ Ventajas Principales

  • Rendimiento de Bloque: Ideal para bases de datos críticas y virtualización (VMware, Hyper-V).
  • Alta Disponibilidad: Rutas redundantes (Multipathing) que eliminan puntos únicos de fallo.
  • Consolidación: Permite gestionar cientos de Terabytes desde una consola central para múltiples servidores.

⚠️ Limitaciones

  • Complejidad Técnica: Requiere personal especializado en redes Fibre Channel y zonificación.
  • Coste Elevado: Los switches SAN y los adaptadores HBA son significativamente más caros que el hardware de red estándar.
  • Infraestructura Dedicada: Requiere cableado y hardware propio.

🏦 Caso de Uso: Transacciones Bancarias en Tiempo Real

Un banco multinacional utiliza una red SAN para gestionar su núcleo transaccional.

La SAN conecta clústeres de bases de datos de alto rendimiento con cabinas de almacenamiento que replican cada bloque de datos instantáneamente en un centro de datos secundario. Esto garantiza que, incluso ante el fallo total de un data center, no se pierda ni una sola transacción financiera y el servicio se restablezca en segundos con una integridad de datos absoluta.
