2.1.1 Conceptos Básicos de Computación Distribuida

El poder de la colaboración: orquestando ejércitos de servidores

La computación distribuida se fundamenta en un ecosistema de nodos interconectados (servidores físicos, virtuales o contenedores) que colaboran para resolver problemas masivos. A diferencia de un sistema centralizado, aquí el trabajo se fragmenta; cada nodo ejecuta una parte del proceso y se comunica con el resto a través de redes de alta velocidad.

El ideal de estos sistemas es la transparencia de distribución: que el usuario final perciba el clúster como una única entidad súper potente, ignorando la complejidad física subyacente.

Pilares del Sistema Distribuido

Descentralización

No existe un único cerebro central. La carga se reparte entre nodos autónomos con su propio procesador y memoria.

Escalabilidad Horizontal

Capacidad infinita de crecimiento añadiendo más máquinas al sistema sin interrumpir el servicio operativo.

Tolerancia a Fallos

Si un servidor "cae", el sistema reasigna sus tareas automáticamente a otros nodos, garantizando la continuidad.

Comunicación en Red

Intercambio de datos eficiente mediante protocolos optimizados como gRPC, HTTP/2 o TCP/IP.

Tecnologías Habilitadoras

📁

HDFS (Hadoop Distributed File System)

Fragmenta archivos en bloques (128 MB) y los replica en múltiples nodos para asegurar que nunca se pierdan.

📡

Apache Kafka

Plataforma de mensajería distribuida líder para la ingesta y flujo de datos en tiempo real a escala masiva.

🌐

Apache Cassandra

Base de datos NoSQL diseñada para la alta disponibilidad sin puntos únicos de fallo, ideal para despliegues globales.

☸️

Kubernetes

El orquestador definitivo que gestiona la vida de los contenedores distribuidos en clústeres dinámicos.

Para + Info: Glosario Técnico

Concepto Descripción Ejemplo Tecnológico
Nodo Máquina física o virtual que ejecuta procesos dentro del sistema distribuido. Servidor EC2 en AWS.
Clúster Conjunto de nodos interconectados que trabajan como un único sistema. Clúster Hadoop.
Replicación Duplicación de datos para asegurar disponibilidad absoluta. Tres copias en HDFS.
Escalabilidad horizontal Añadir nuevos nodos sin detener el sistema operativo. Añadir nodos Kafka en producción.

Sistemas Distribuidos en Producción

🛒

E-commerce: Tolerancia con HDFS

Una empresa almacena 10 TB de transacciones. HDFS divide estos datos en bloques de 128 MB y los replica en tres nodos distintos. Si un nodo falla físicamente, los datos siguen accesibles en los otros dos.

Esta estrategia garantiza que el negocio nunca se detenga por fallos de hardware individuales.
🎬

Streaming: Disponibilidad Global con Cassandra

Una plataforma de video utiliza clústeres de **Apache Cassandra** repartidos por todo el mundo. Durante el estreno de un éxito global, el sistema añade nodos automáticamente en las regiones con más tráfico.

Al escalar de forma horizontal, se mantiene una latencia de acceso inferior a 100 ms para millones de usuarios simultáneos.
