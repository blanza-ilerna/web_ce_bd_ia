2.3.6.2 Apache HBase

Bases de datos masivas: acceso aleatorio y tiempo real sobre HDFS

Apache HBase es una base de datos NoSQL de código abierto orientada a columnas que se ejecuta sobre el sistema de archivos HDFS. A diferencia del procesamiento *batch* tradicional de Hadoop, HBase está diseñada para proporcionar acceso aleatorio y lectura/escritura en tiempo real sobre miles de millones de filas y millones de columnas.

Es la solución ideal cuando se requiere la escalabilidad masiva de Hadoop pero con la latencia baja de una base de datos tradicional.

Pilares Técnicos de HBase

📊

Orientación a Columnas

Optimizado para el almacenamiento de datos dispersos (sparse) y semiestructurados. Permite consultas extremadamente rápidas sobre conjuntos específicos de atributos sin leer toda la fila.

🚀

Escalabilidad por Regiones

Las tablas se fragmentan horizontalmente en "regiones" distribuidas automáticamente entre los nodos del clúster, permitiendo un crecimiento lineal y fluido.

🔗

Integración con el Ecosistema

Utiliza HDFS para el almacenamiento persistente y se apoya en Apache Zookeeper para la gestión de estados y coordinación de alta disponibilidad.

Aplicación Práctica: Mensajería Instantánea

💬

Almacenamiento de Mensajes en Tiempo Real

Las redes sociales modernas utilizan HBase para gestionar el flujo incesante de mensajes de usuarios. La capacidad de realizar lecturas y escrituras atómicas en milisegundos asegura que las conversaciones sean fluidas, independientemente del número de usuarios activos.
